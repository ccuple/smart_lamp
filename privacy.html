Політика конфіденційності

Ця політика конфіденційності описує, як мобільний додаток SmartLamp (надалі — "Додаток") взаємодіє з інформацією користувачів.

1. Збір та використання персональних даних

Додаток створено як інструмент для керування нічником через Bluetooth. Ми з упевненістю заявляємо, що Додаток:

  • НЕ збирає, не відстежує та не зберігає жодних персональних даних користувачів (таких як ім'я, телефон, електронна пошта тощо).
  • НЕ збирає унікальні ідентифікатори пристроїв (наприклад, Android ID або MAC-адреси).
  • НЕ використовує сторонні аналітичні сервіси або рекламні мережі, які можуть відстежувати вашу активність.

2. Робота з мережею та топіками

Додаток вимагає доступу до мережі Інтернет виключно для виконання своєї основної функції — читання та відправки технічних команд (топіків) на сервер/брокер для керування пристроєм. Усі дані, що передаються у топіках, є суто технічними командами керування нічником.

2. Дозволи додатка

Додаток використовує мінімальний набір дозволів, необхідних для роботи (зокрема, дозвіл на доступ до Bluetooth). Ці дозволи використовуються виключно для забезпечення взаємодії з вашим нічником.

3. Зміни до політики конфіденційності

Ми можемо час від часу оновлювати цю Політику конфіденційності. Будь-які зміни вступають в силу з моменту їх публікації на цій сторінці.

4. Контакти

Якщо у вас виникли запитання щодо цієї Політики, ви можете звернутися до розробника через сторінку проєкту на GitHub або прямо через електронну адресу valerava1@i.ua.
